# Websites in 2026

A single-page showcase of three animated, 2026-style website designs —
the same three from the reference reel:

1. **OHO ENERGY** — energy drink site, glossy 3D cans floating and rotating.
2. **Emons** — logistics company, colourful isometric illustration that pans
   across warehouses, trucks, ships, airplanes and trains.
3. **ORTOO** — AI-powered product, minimalist photography and smooth
   transitions.

Open `index.html` in a browser, or visit the live page:
https://ndrean7.github.io/websites-in-2026/

Original build, no template. The three brand names are the ones shown in
the reference reel; the pages themselves are original.
